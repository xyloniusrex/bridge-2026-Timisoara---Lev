# Bridge 2026 Timisoara - Lev

Photos from the Bridge 2026 conference in Timisoara, shot by Lev.

## Downloading all the photos

The full-resolution `.ARW` raw files are tracked with Git LFS in this repo, but if you just want a plain zip download without setting up Git/LFS, grab them from the **Releases** page instead:

**[Download all photos (release v1.0)](https://github.com/xyloniusrex/bridge-2026-Timisoara---Lev/releases/tag/v1.0)**

The files are split into 8 zip parts (`part01.zip`–`part08.zip`, ~1.8GB each except the last). To get everything:

1. Open the [release page](https://github.com/xyloniusrex/bridge-2026-Timisoara---Lev/releases/tag/v1.0).
2. Download all 8 `partXX.zip` files.
3. Extract each one into the same destination folder — the `.ARW` files will all land together.

(Raw files in this repo itself live under [`photos/`](photos/).)

If you'd rather clone the repo directly with full LFS support:

```
git lfs install
git clone https://github.com/xyloniusrex/bridge-2026-Timisoara---Lev.git
```

## JPEG versions

Two JPEG sets are available, both as a folder in this repo and as a single zip on the **Releases** page:

- **[`jpegs/`](jpegs/) / full JPEG set release](https://github.com/xyloniusrex/bridge-2026-Timisoara---Lev/releases/tag/jpegs-v1)** — straight full-resolution JPEG conversion of all 256 raws (camera white balance, no edits), ~1.4GB.
- **[`edited/`](edited/) / edited best shots release](https://github.com/xyloniusrex/bridge-2026-Timisoara---Lev/releases/tag/edited-best-v1)** — the 28 best shots below, with per-photo color/exposure/local edits applied, ~510MB.
